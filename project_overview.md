SWYNEX Final Data Analytics Project

Project Overview

This project brings together the work completed during my data analytics internship with SWYNEX Technologies. It covers data cleaning, exploratory data analysis, and interactive sales dashboard development.

Project Objectives

- Clean and prepare retail transaction data using Python and Pandas.
- Analyze sales trends and patterns.
- Identify top-performing products and countries.
- Present business insights through a Power BI dashboard.

Project Tasks

1. Task 1 – Data Cleaning: Cleaned and prepared the retail dataset.
2. Task 2 – Exploratory Data Analysis: Analyzed revenue, transactions, products, and country-wise sales.
3. Task 3 – Interactive Dashboard: Developed a sales dashboard using Microsoft Power BI.
4. Task 4 – Final Project: Documented the complete workflow and key business findings.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- Microsoft Power BI
- GitHub
